# Phase 04.1 Plan 04.1-03: Stories Routes Summary

**Stood up the `/stories/{slug}/` URL contract with 46 static paths sourced from a hand-curated `src/data/stories.json` manifest, a build-time cascade extractor (`<main>` → `<article>` → throw, NO raw body fallback per B-3) with single-pass chrome scrubber (B-4), and a new `pageType='story'` RootLayout prop (B-1) that makes dormant-archive stories (rendlesham/uk, trans-en-provence/geipan, varginha/brazil, falcon-lake/canada) first-class indexable pages — Pagefind index grew 4 → 51 pages, all 8 featured stories build at ≤ 44 KB each, zero chrome leakage in any built `<article class="story-body">`.**

## What was built

### Task 0 — `RootLayout.astro` `pageType` prop (B-1 fix) · commit `1be2cb4`

Added an optional `PageType = 'archive' | 'story' | 'site-page'` literal-union prop to `RootLayout.astro` (one line, same `@astrojs/compiler 2.13.1` constraint as `ArchiveSlug`). Default `'archive'` preserves every pre-04.1 call site's behaviour (aaro/nasa/nara/index, wargov index, nz, uruguay, search, etc.). For `pageType === 'story' || 'site-page'`, a new `forceIndexing` flag overrides the `ACTIVE_ARCHIVES` gate so `<main>` ALWAYS emits `data-pagefind-body` and NEVER emits `data-pagefind-ignore` — regardless of `archiveSlug`.

This is the prerequisite for dormant-archive stories (uk/geipan/brazil/canada) to be visible in Pagefind: without it, `data-pagefind-ignore` on the parent `<main>` would mask any inner `data-pagefind-body` per pagefind.app/docs/indexing.

Build regression-test: `dist/aaro/index.html` still has `data-pagefind-body` (active, default pageType), `dist/nz/index.html` still has `data-pagefind-ignore` (dormant, default pageType). No behaviour change for any existing page.

### Task 2 — extractor + dynamic route · commit `b6ef044`

**`src/scripts/extractLegacyBody.ts`** — pure TypeScript, no runtime deps.

- `extractMain(html, filePath): string` — walks the CASCADE: `<main\b[^>]*>([\s\S]*?)<\/main>` → `<article\b[^>]*>([\s\S]*?)<\/article>`. First match returns inner HTML; if NEITHER matches, THROWS with an error pointing at `filePath` and instructing the operator to either extend the cascade + audit, or remove the file from `stories.json`. **B-3 fix: no raw body fallback.**
- `scrubChrome(html, { preserveScripts? }): string` — single-pass 7-category scrub: `<style>...</style>`, `<link rel="stylesheet" ...>`, `<script>...</script>` (only when `preserveScripts !== true`), `<header>...</header>`, `<footer>...</footer>`, `<div class="...scanlines...">...</div>`, and ALL inline `style="..."` attributes. **B-4 fix.** Idempotent.

**`src/pages/stories/[slug].astro`** — dynamic route. `getStaticPaths()` returns one entry per `stories.json` row: reads `legacyPath` via `fs.readFileSync`, runs `extractMain` (B-3 throw on miss), then `scrubChrome` (B-4 chrome strip). Page renders inside `<RootLayout archiveSlug={archive} pageType="story">` with a hero block (source archive + incident date + verbatim title + source link), `<article class="story-body" data-pagefind-body set:html={bodyHtml}>`, an "← All stories" back link, and a "Related" rail with 2 same-archive siblings + a "Browse all stories →" card.

**`src/styles/stories.css`** — typography (65ch, `var(--serif)`, 16/15 px) for `.story-body`, card grid (minmax(280px, 1fr) desktop · 1fr mobile per CLAUDE.md §8), and back-link / related-rail styles. All colours via existing palette vars — no deviation from CLAUDE.md §3.2.

### Task 3 — stories index at `/stories/` · commit `5131dc4`

`src/pages/stories/index.astro` mirrors the `src/pages/aaro/index.astro` skeleton (hero → archive-section → stats-grid → arch-controls-bar → arch-grid) but simplified for stories: no pagination (46 entries fit on one page), no lightbox (text-only cards), no agency/type tabs. Wrapped in `<RootLayout archiveSlug="wargov" pageType="story">`.

Hero: italic "Stories" heading + lede ("Curated case narratives from official government UAP sources…"). Stats grid: Total stories (46) · Archives covered (15). Controls bar: search input with 80 ms debounce + sort select (featured/title A→Z/title Z→A/archive/date new/date old). Grid: all 46 stories with featured leading (orders 1–8), then by archive. Each card carries `data-archive`, `data-slug`, `data-title`, `data-date`, `data-featured` so the inline filter+sort script can mutate display without a framework.

`?q=` URL persistence wired per CLAUDE.md §7 invariant 8 — restored on load, `history.replaceState` on input. No `client:*` directive — pure `<script is:inline>`.
