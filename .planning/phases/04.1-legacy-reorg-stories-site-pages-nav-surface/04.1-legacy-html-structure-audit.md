## Selector cascade (extractor contract for Plans 04.1-03 + 04.1-04)

Plans 04.1-03 Task 2 (stories extractor) and 04.1-04 Task 2 (site-pages extractor) MUST use this cascade in order, **first match wins**:

1. **`<main\b[^>]*>([\s\S]*?)<\/main>`** — preferred selector. Matches 55 of 89 files (every project-authored legacy story HTML + 6 of 6 SSG-wrap-able site pages: about, foia, glossary, whatsnew, timeline; note `stats`, `donate`, `compare` are 410/parked).

2. **`<article\b[^>]*>([\s\S]*?)<\/article>`** — fallback selector. Matches the 10 dormant-archive `<slug>/index.html` files where the pre-Phase-4 build script wrapped content in `<article>` instead of `<main>`. Use only if (1) does not match.

3. **Per-shape custom selectors** (last resort, applied only to specific files explicitly named below — NOT a generic catch-all):

   - **`legacy/aaro/details.html`** — `<div class="container">([\s\S]*?)<\/div>\s*<footer` (concat from container opening through the close immediately before `<footer>`). The file's only structural anchor is `<div class="container">` (no `<main>`, no `<article>`), but the chrome (Nav, Footer, scanlines) lives in `<div class="header-wrap">` and `<footer>` siblings, NOT inside `.container` — so this selector is safe for this one file.

   - **`legacy/map.html`** — Concat the body region between `</div>\s*<!--\s*end header-wrap\s*-->` (or equivalent: the closing `</div>` of the outermost `header-wrap`) and `<footer` opening. This captures `<section id="map">` + `<div class="legend">` + inline body scripts (Leaflet init at lines ~181, ~294, ~312 of legacy/map.html). See "Script preservation whitelist" below.

4. **NEVER fall back to raw `<body>`.** Raw `<body>` extraction in pre-Phase-4 files would double-render Nav/Footer/scanlines because the legacy build pipeline embedded its own page chrome. If no selector in steps 1-3 matches, the extractor MUST FAIL the build with a clear error pointing to the offending file:

   ```
   Extractor: no recognised structural anchor in legacy/<path>.
   Either add a documented per-shape selector to extractLegacyBody.ts (see audit §"Selector cascade"),
   OR mark the file as out-of-scope in stories.json / site-pages.json and rely on the legacy 301 redirect.
   ```

## Extractor implementation hints (informational — Plans 04.1-03 + 04.1-04 own implementation)

- Run cascade selector 1, then 2, then per-file step 3. First non-empty match wins.
- Strip `<script id="nav-script-shared">` blocks unconditionally from extracted content (they duplicate Astro Nav.astro behavior).
- Strip `<script>` blocks that match the legacy SW registration pattern `if("serviceWorker" in navigator)` (Astro RootLayout owns SW registration via BaseHead.astro).
- Preserve all `<img src="...">` and `<a href="...">` attributes verbatim — relative paths resolve against the new `/stories/<slug>/` or `/<page>/` route. Plan 04.1-04 OR 04.1-05 may need to rewrite asset paths from `aaro/assets/...` to `/aaro/assets/...` if any legacy file references them relatively.
- For Plan 04.1-04 site pages with body-tail scripts (map, timeline): pass `preserveScripts: true` plus an explicit allow-list of script positions in the page's `src/data/site-pages.json` entry.
