## 2. Nav surface — additions

### 2.1 Desktop (≥ 720 px)

Current 4-archive cross-nav extended with two dropdown groups:

```
[seal] U.S. Department of War  ☰     WAR.GOV · AARO · NASA · NARA · STORIES ▾ · ABOUT ▾
```

- `STORIES ▾` and `ABOUT ▾` are nav-list `<li>` siblings of the 4 archive links.
- Right-aligned within `.primary` nav, after archive links.
- Dropdown trigger: pure CSS `:hover` + `:focus-within` reveal. **No JS framework.**
- Keyboard: `Tab` moves into trigger, `Enter`/`Space` toggles, `Esc` closes, arrow keys cycle items. Implement via small `<script is:inline>` block in `Nav.astro` extending the existing hamburger pattern.

#### Dropdown panel

- Position: absolute, top: 100%, right: 0 (right-aligned to avoid viewport overflow).
- Background: `var(--panel)` (#15151a) with `var(--rule-strong)` 1 px border.
- Padding: `12px 0` (vertical), `0` horizontal. Items: `padding: 10px 16px`.
- Min-width: 220 px. Max-width: 320 px.
- Typography: mono, 13 px, letter-spacing 0.08 em (matches nav links).
- Item hover: `background: rgba(232,227,216,0.06)` + colour: `var(--caution)` (per-archive accent).
- No inline ↗ on items.
- 44 px touch-target minimum (per CLAUDE.md §8).

## 3. New page types

### 3.1 `/stories/{slug}/` — story detail page

Skeleton (mirrors CLAUDE.md §4):

```
<scanlines>
<header-wrap>                                     — global Nav.astro (highlights STORIES)
<hero>
   .coords           ◉ source archive label (e.g. "AARO · 2004 USS Nimitz")
   h1.hero-title     case name (italic accent on one word)
   p.hero-sub        lede paragraph from legacy <article> + "Source: aaro.mil ↗"
<article.story-body>  — wraps the verbatim extracted <main> from legacy HTML
                       Typography: serif body, 16 px desktop / 15 px mobile, max-width 65 ch
                       Inline images allowed (verbatim from legacy)
<section.related>     — 3-card grid: "Other stories from {archive}" + "Browse all stories"
<footer>              — global Footer.astro
```

- `data-pagefind-body` on `<article.story-body>` so search indexes story prose.
- Tone colour: derived from `archive` field in `stories.json` → uses that archive's `--caution` variable.
- Per CLAUDE.md §9: verbatim official text. No paraphrase, no filler intro added by Astro layer.

### 3.2 `/stories/` — story index

Same skeleton as archive index page (`src/pages/aaro/index.astro` is the analog). Stats grid + archive-grouped story cards.

```
<hero>
   h1                "Stories"
   p.hero-sub        "Curated case narratives from official government UAP sources."
<section.stats>      Total stories: N · Across {M} archives
<section.archive>
   .arch-controls-bar   — search input + sort dropdown + group toggle (by archive / by date)
   .arch-grid           — story cards, minmax(280 px, 1fr) desktop / 1fr mobile
<footer>
```

Story card schema:
```
title        case name (verbatim)
desc         first 160 chars of legacy <article> lede
agency       source archive (uppercase mono)
date         incident date (if known) or release date
thumb        repo-relative thumb path (if present in legacy)
url          /stories/{slug}/
```

### 3.3 `/about/`, `/foia/`, `/glossary/`, `/map/`, `/timeline/`, `/whatsnew/` — site pages

Skeleton (simpler — no archive nav highlight, just `RootLayout`):

```
<scanlines>
<header-wrap>           — Nav.astro highlights ABOUT
<hero>
   h1                   page title
   p.hero-sub           one-sentence purpose
<article.page-body>     — verbatim <body> content extracted from legacy HTML
                          data-pagefind-body
<footer>
```

For `/map/` and `/timeline/` — these contain interactive JS in the legacy HTML. Preserve `<script>` blocks during extraction so behaviour is unchanged.

For `/about/`, `/foia/`, `/glossary/`, `/whatsnew/` — pure prose; no JS extraction needed beyond standard nav/lightbox.

## 4. Quality gates

- **6-pillar visual audit (gsd-ui-checker):**
  1. Hierarchy: hero → body → related/footer
  2. Spacing: 16 px gutter, 24 px section gaps, 64 px hero padding-top
  3. Mobile-first: 360 px baseline tested — no overflow, hamburger works, dropdowns collapse
  4. Contrast: text on `var(--bg)` meets WCAG AA (≥ 4.5:1 for body)
  5. Touch targets: ≥ 44 px for all dropdown items and section toggles
  6. Pattern parity: hero/card/footer match existing archive pages
- **Pagefind: new pages must be indexed.** Verify by running `pnpm build` and `pnpm exec pagefind --site dist`, then querying for "tic-tac", "FOIA", "glossary" — each should return ≥ 1 hit.
- **Lighthouse budgets:** Per Phase 4 close, new pages must hit existing budget thresholds (LH ≥ 0.95 perf on /). Verify after build.

---

## 5. Out of scope (deferred)

- Per-story custom theme tweaks (every story uses its source archive's `--caution`).
- Story tagging / search facets (Pagefind defaults sufficient).
- Tooltips / hover-previews on STORIES ▾ items.
- Animation on dropdown reveal (instant show; matches existing nav).
- A11y deep-dive beyond standard nav patterns (gsd-ui-checker covers).
