## Goal

Stand up the `/stories/` URL contract: a curated index at `/stories/` and dynamic detail pages at `/stories/{slug}/`. Stories are sourced from a hand-maintained `src/data/stories.json` manifest mapping slug → legacy HTML file path → archive slug → featured flag. Each story's body is extracted at build time from `legacy/<archive>/<case>.html` using a documented selector cascade (`<main>` → `<article>` → audited fallbacks; NEVER raw `<body>` — see B-3 fix and 04.1-legacy-html-structure-audit.md from Plan 04.1-01 Task 5), then scrubbed to remove legacy chrome (`<style>`, `<link rel="stylesheet">`, `<script>` (except whitelist), `<header>`, `<footer>`, scanlines divs, inline `style=""` attributes — see B-4 fix). The remaining VERBATIM TEXT (paragraphs, headings, lists, images, links — per CLAUDE.md §9) is wrapped in `RootLayout` with `pageType="story"` (B-1 fix: ensures Pagefind indexes dormant-archive stories like rendlesham/trans-en-provence/varginha/falcon-lake) and the source archive's `archiveSlug` so they inherit that archive's tone colour. The Nav `STORIES ▾` dropdown is NOT extended in this plan — that's 04.1-05. Redirects from legacy `.html` paths to `/stories/{slug}/` are NOT added in this plan — that's 04.1-06.

**Step 1 — Create `src/scripts/extractLegacyBody.ts`** as a shared, dependency-free, plain-TypeScript module (no Astro imports, no runtime deps — pure regex). Shape:

```typescript
// extractLegacyBody.ts — Phase 04.1 legacy HTML extractor + chrome scrubber.
// Consumed by src/pages/stories/[slug].astro and src/pages/{about,foia,
// glossary,map,timeline,whatsnew}.astro at build time. See
// .planning/phases/04.1-legacy-reorg-stories-site-pages-nav-surface/
// 04.1-legacy-html-structure-audit.md for the selector cascade contract.

// Cascade selectors in priority order. First match wins. Final entry
// FAILS — there is no raw <body> fallback (B-3 fix per
// 04.1-PLAN-CHECK.md §3): falling back to <body> double-renders legacy
// Nav/Footer/scanlines around the new RootLayout shell.
const CASCADE: ReadonlyArray<{ re: RegExp; name: string }> = [
  { re: /<main\b[^>]*>([\s\S]*?)<\/main>/i,       name: '<main>' },
  { re: /<article\b[^>]*>([\s\S]*?)<\/article>/i, name: '<article>' },
  // Documented fallbacks from 04.1-legacy-html-structure-audit.md.
  // The audit drives which of these are uncommented; default-disable
  // until the audit confirms a selector is unique within its file shape.
  // Example: { re: /<div\s+class="page-content"\b[^>]*>([\s\S]*?)<\/div>/i, name: '<div.page-content>' },
];

export function extractMain(html: string, filePath: string): string {
  for (const { re } of CASCADE) {
    const m = html.match(re);
    if (m) return m[1];
  }
  throw new Error(
    `extractMain: no recognised structural anchor in ${filePath}. ` +
    `Audit the file in 04.1-legacy-html-structure-audit.md and add a ` +
    `selector to extractLegacyBody.ts CASCADE, OR remove the file from ` +
    `stories.json/site-pages.json. Raw <body> fallback is forbidden ` +
    `(B-3 fix).`,
  );
}

export interface ScrubOptions {
  /** Stories: false. Site-pages map/timeline: true. Default false. */
  preserveScripts?: boolean;
}

export function scrubChrome(html: string, opts: ScrubOptions = {}): string {
  let out = html;
  // 1. <style>…</style>
  out = out.replace(/<style\b[^>]*>[\s\S]*?<\/style>/gi, '');
  // 2. <link rel="stylesheet" …> (self-closing or void)
  out = out.replace(/<link\b[^>]*\brel=["']?stylesheet["']?[^>]*\/?>/gi, '');
  // 3. <script>…</script> — UNLESS preserveScripts is true.
  //    Even with preserveScripts true, callers are expected to pass only
  //    the EXTRACTED ANCHOR SLICE (not legacy <head>) so head-scripts
  //    never leak (W-4 fix).
  if (!opts.preserveScripts) {
    out = out.replace(/<script\b[^>]*>[\s\S]*?<\/script>/gi, '');
  }
  // 4. <header>…</header> — legacy chrome competing with Nav.astro.
  out = out.replace(/<header\b[^>]*>[\s\S]*?<\/header>/gi, '');
  // 5. <footer>…</footer> — legacy chrome competing with Footer.astro.
  out = out.replace(/<footer\b[^>]*>[\s\S]*?<\/footer>/gi, '');
  // 6. <div class="scanlines" …></div> — legacy overlay; RootLayout
  //    emits its own .scanlines div, so duplicates would stack.
  out = out.replace(/<div\b[^>]*class=["'][^"']*\bscanlines\b[^"']*["'][^>]*>[\s\S]*?<\/div>/gi, '');
  // 7. Inline style="…" attributes (any tag). Legacy hard-coded
  //    colours conflict with CLAUDE.md §3.2 tone palette.
  out = out.replace(/\s+style=["'][^"']*["']/gi, '');
  return out;
}
```
