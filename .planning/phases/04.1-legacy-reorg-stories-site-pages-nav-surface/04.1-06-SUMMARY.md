### Task 2 — build-redirects.py extension + _redirects regeneration (commit de9ce09)

- Added module-level constants: `STORIES_JSON`, `SITE_PAGES_JSON`, `PARKED_UTILITIES`, `PARKED_TARGET`, `AARO_DETAILS_TARGET`, `LEGACY_PATH_RE`.
- New helper `build_legacy_301_block()`:
  - Reads `stories.json` — for each entry whose `legacyPath` matches `^legacy/(.+)\.html$`, emits `/<captured>.html /stories/<slug>/ 301` (43 rules)
  - Reads `site-pages.json` — for each entry emits `/<slug>.html /<slug>/ 301` (6 rules)
  - Emits parked-utility redirects for `donate`, `embed`, `compare`, `stats` → `/about/` (4 rules)
  - Emits AARO master case index special case `/aaro/details.html → /stories/aaro-overview/` (1 rule)
  - Defensive: warns on stderr (rather than crashing) if a `legacyPath` is non-conforming or `slug` missing
  - Output sorted for deterministic diffs across regenerations
  - Prefixed by sentinel comment block: `# === Phase 04.1 — Legacy .html → canonical 301s ===`
- `render_redirects()` now appends `build_legacy_301_block()` AFTER the existing canonical 200-rewrite block.
- `main()` updates the rule-count summary to expose `legacy_301_count` for `--check` and write-mode telemetry.
- Updated module docstring to document the new inputs and the W-5 regression-resilience contract.

## Deviations from Plan

### Auto-added Issues

**1. [Rule 2 — Missing critical functionality] URL-CONTRACT.txt augmentation included active + dormant archive root routes**

- **Found during:** Task 1
- **Issue:** The plan's Step 3 augmentation only adds `/stories/*` + the 6 site-page routes from JSON manifests. Running `snapshot-urls.py` post-Plan-04.1-01 yields ZERO entries (every tracked `.html` is now under `legacy/`, which is excluded). Without auto-adding live archive roots, the URL contract would be missing `/`, `/aaro/`, `/nasa/`, `/nara/` (Astro-built) and the 9 dormant archive index routes (`/geipan/`, `/uk/`, etc. — still shipped by `copy-legacy-archives.sh`). The contract would be incomplete relative to the live URL surface.
- **Fix:** Augmented the JSON-manifest-driven additions with: 4 active archive root routes, 9 dormant archive root routes (derived from `legacy/<slug>/index.html` git-ls-files presence), and `/search.html`. Documented in URL-CONTRACT.txt header comment.
- **Files modified:** URL-CONTRACT.txt
- **Commit:** b6ce318
- **Justification:** Rule 2 — URL contract must reflect actual live routes for the `_redirects` 200-rewrite block to override CF Pages' default 302 behaviour on those paths. Without this, `/aaro/` direct hits would receive default routing instead of the explicit canonical contract.

**2. [Rule 2 — Defensive logging] Non-conforming `legacyPath` in stories.json warned, not crashed**

- **Found during:** Task 2 implementation
- **Issue:** `LEGACY_PATH_RE.match()` returning None on a malformed entry would raise an `AttributeError` if `.group(1)` were called unconditionally.
- **Fix:** Added explicit None check + stderr warning + `continue`. The build proceeds with the remaining valid entries.
- **Files modified:** scripts/build-redirects.py
- **Commit:** de9ce09
- **Justification:** Rule 2 — defense-in-depth. The manifest is hand-maintained per CONTEXT.md decision; future editor errors should produce loud warnings, not crashing builds.
