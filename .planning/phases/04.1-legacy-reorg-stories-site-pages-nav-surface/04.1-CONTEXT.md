## Phase Boundary

Phase 04 (full migration) closed 2026-05-28 shipping 4 active archives (wargov/aaro/nasa/nara) wired into Nav + Footer + Pagefind. Legacy HTML files remain at repo root in two piles:

1. **Story sub-pages** — ~30 curated case narratives across active (aaro/, nara/, nasa/) and dormant (chile/, brazil/, canada/, geipan/, nz/, spain/, uk/, italy/, peru/, argentina/, uruguay/) archive directories. Each is a full HTML page authored from official gov sources. Currently shipped to dist via `scripts/copy-legacy-archives.sh` (Pile B partial-port + Pile A dormant wholesale) but invisible to navigation.
2. **Top-level site-pages** — `about.html`, `foia.html`, `glossary.html`, `map.html`, `timeline.html`, `whatsnew.html`, `donate.html`, `embed.html`, `compare.html`, `stats.html`, `404.html`. Some live in `_redirects` + `URL-CONTRACT.txt` but only `stats/timeline/whatsnew` actually ship to dist (per copy-legacy-archives.sh). Rest are orphaned at root, returning 404 in prod.

This phase: (a) move all legacy HTML into `legacy/` folder to clean repo root, (b) expose curated stories under new `/stories/{slug}` URL contract via grouped nav surface, (c) re-activate informational site-pages under chosen URL contract via grouped nav surface, (d) update `copy-legacy-archives.sh` paths so dist output unchanged for live URLs, (e) preserve URL contract for live legacy URLs via redirects.

**Out of scope:** Re-activating dormant archive index pages (geipan/, uk/, etc.) in Nav — those stay dormant per CLAUDE.md §2 status. Rewriting story content (verbatim official text per §9). New Astro pages for previously-broken site-pages (donate/embed/compare/stats stay in legacy/, redirected to gone-410).

<decisions>
## Implementation Decisions

### Legacy reorg layout

- `legacy/` directory created at repo root.
- Moved into `legacy/`:
  - **Story sub-pages** in each archive dir: `aaro/*.html` (except `aaro/index.html` — Astro owns), `nara/*.html` (except `nara/index.html`), `nasa/story.html`, and the entire dormant archive directories (`geipan/`, `uk/`, `brazil/`, `chile/`, `argentina/`, `canada/`, `italy/`, `nz/`, `peru/`, `spain/`, `uruguay/`).
  - **Root utility HTMLs**: `about.html`, `foia.html`, `glossary.html`, `map.html`, `timeline.html`, `whatsnew.html`, `compare.html`, `donate.html`, `embed.html`, `stats.html`, `404.html`, `index.html` (legacy War.gov SPA).
- **NOT moved:** Astro-owned routes (`src/`, `public/`), assets (`assets/`, `slideshow/`, `slideshow-2/`, `bundles/`), data (`data/`, `feeds/`, `api/`, `release-manifest.json`, `uap-*.csv`), config, scripts, workers, tests.
- Per-archive `assets/` and `pages/` subdirectories (aaro/assets/, aaro/pages/, nara/assets/, nara/pages/, nasa/assets/) move under `legacy/` with their parent archive dir.

### URL contract — stories

- New surface: `/stories/{slug}/` (trailing slash matches `trailingSlash: 'ignore'` Astro config).
- Slug convention: bare case slug for unique cases (`/stories/tic-tac/`, `/stories/roswell/`, `/stories/rendlesham/`). Per-archive "overview" pages (the generic `story.html` in each archive dir) get `/stories/{archive}-overview/` (e.g. `/stories/aaro-overview/`, `/stories/nara-overview/`).
- Story page renders via `src/pages/stories/[slug].astro` dynamic route + content collection. Story content extracted from `legacy/<archive>/<case>.html` `<main>` or `<article>` body at build time (preserving verbatim official text per CLAUDE.md §9). Wrapped in `RootLayout` for nav/footer/scanlines/favicon parity.
- Story index page `/stories/` lists all stories grouped by source archive. Cards link to `/stories/{slug}/`.
- Redirects: every legacy story path 301 → new slug. Examples:
  - `/aaro/tic-tac.html` → `/stories/tic-tac/`
  - `/nara/roswell.html` → `/stories/roswell/`
  - `/nasa/story.html` → `/stories/nasa-overview/`
  - `/chile/story.html` → `/stories/chile-overview/`
- `aaro/details.html` (AARO master case index) → `/stories/aaro-overview/`.

### URL contract — site pages

- Bare-root paths, no `.html` extension:
  - `/about/` — what is realufo, mission, archive scope
  - `/foia/` — FOIA primer + jurisdiction table
  - `/glossary/` — UAP terminology
  - `/map/` — case pin map viewer
  - `/timeline/` — chronological case browser
  - `/whatsnew/` — release/update log
- Each rendered via `src/pages/{slug}.astro` (or `src/pages/{slug}/index.astro` for trailing-slash parity).
- Approach: extract `<body>` content from `legacy/<file>.html`, wrap in `RootLayout`. Use a thin Astro helper or build-time fetch — implementation detail for planner.
- 301 redirects: `/about.html` → `/about/`, etc.
- **Park (not migrated, redirect to 410-gone or `/about/`):** `donate.html`, `embed.html`, `compare.html`, `stats.html`. These remain in `legacy/` for history but are not Astro-routed. `_redirects` returns 410 (or 301 to `/about/`) so direct hits fail clean.
- `404.html`: Astro 404 already handled — `legacy/404.html` is reference only.

### Nav surface — grouped dropdowns

- Nav structure (desktop ≥720 px):
  ```
  WAR.GOV  |  AARO  |  NASA  |  NARA  |  STORIES ▾  |  ABOUT ▾
  ```
  - `STORIES ▾` opens dropdown listing top ~8 curated stories + "All stories →" link to `/stories/`. (Top ~8 picked by editorial pick; full list lives on `/stories/`.)
  - `ABOUT ▾` opens dropdown with: About, FOIA, Glossary, Map, Timeline, What's New.
- Mobile (<720 px): hamburger menu lists archives → Stories (collapsible section) → About (collapsible section) — no horizontal scroll per CLAUDE.md §8.
- Dropdown CSS: pure CSS hover for desktop, click-to-toggle (`aria-expanded`) for mobile. No JS framework. Reuse existing `<script is:inline>` pattern in `Nav.astro`.
- Touch targets ≥ 44 px per CLAUDE.md §8.
- No inline ↗ in dropdown items (CLAUDE.md §11).

### Footer surface

- Add new column "Pages" listing the 6 site pages (`/about/`, `/foia/`, `/glossary/`, `/map/`, `/timeline/`, `/whatsnew/`).
- Add new column "Stories" with `/stories/` index link + top 4–6 curated.
- Existing "Source" and "Archives" columns unchanged.

### Build pipeline changes

- `scripts/copy-legacy-archives.sh`:
  - Iterate over `legacy/<archive>/` instead of `<archive>/` for the 9 dormant archive wholesale copies. Strip `legacy/` prefix from dist target so URL stays `/<archive>/` (no `/legacy/<archive>/`).
  - Iterate over `legacy/<archive>/*.html` for partial-port story sub-pages (aaro/nara/nasa). Strip `legacy/` prefix so `legacy/aaro/tic-tac.html` lands at `dist/aaro/tic-tac.html` if (and only if) we keep the legacy URL alive during transition. **But:** after redirects are wired, these copies become redundant. Plan B: drop the copy and rely on `_redirects` to 301 → `/stories/{slug}/`.
  - Drop `search.html stats.html timeline.html whatsnew.html` top-level copies (now Astro-served or redirected).
  - Drop `assets slideshow slideshow-2` copies if those move into `legacy/` — BUT some are referenced from Astro src (e.g. slideshow-2 hydrated via normalize-csv.py). KEEP at root: `assets/`, `slideshow/`, `slideshow-2/`, `bundles/`. They are NOT legacy.
- `scripts/extract-pdf-text.py`, `scripts/build-redirects.py`, `scripts/extract-fidelity-samples.py`, `scripts/snapshot-urls.py`, `scripts/fix-a11y-sweep.py` — update any hard-coded paths to `<archive>/` or root HTMLs to use `legacy/` prefix. Audit grep-driven.

### URL contract (`URL-CONTRACT.txt`) + `_redirects` updates

- Append new canonical routes: `/stories/`, `/stories/{slug}/` (enumerated), `/about/`, `/foia/`, `/glossary/`, `/map/`, `/timeline/`, `/whatsnew/`.
- Mark legacy `.html` paths as 301-redirects to new canonical (in `_redirects`).
- Park-then-410 entries: `/donate.html`, `/embed.html`, `/compare.html`, `/stats.html` → 410-gone or 301 to `/about/`.
- `scripts/build-redirects.py` regenerates `_redirects` from `URL-CONTRACT.txt`; drift gate (quality-gates.yml) re-runs on commit.

### Content collection vs file-glob

- Use a lightweight **manifest** approach over Astro content collections for stories: enumerate `legacy/<archive>/<case>.html` files at build time via `getStaticPaths()` in `src/pages/stories/[slug].astro`. Each path entry pulls title/date/agency from the legacy HTML's `<meta>` and `<h1>` (already structured).
- A `src/data/stories.json` (build-generated or hand-maintained) maps slug → legacy file path + display title + featured flag (for top-8 nav dropdown). Hand-maintained is simpler and matches the curation intent ("well prepared stories"). Editorial control via flat JSON.
- Site pages handled the same way: `src/data/site-pages.json` maps slug → legacy file path + nav label.

### Risk mitigations

- Pagefind index rebuild: new `/stories/{slug}/` + `/about/`, `/foia/`, etc. pages emit `data-pagefind-body` via `RootLayout`. Search corpus grows by ~36 pages. CLAUDE.md §2 still says dormant pages emit `data-pagefind-ignore`; preserve that so dormant archive index pages stay un-indexed even after legacy/ move.
- Drift gates: re-run `scripts/build-redirects.py`, `scripts/verify-redirects.sh`, `pnpm build`, Lighthouse budget check before commit.
- Phase 5 (scrape automation, executing) does not touch nav or URL contract — no collision.
- Phase 6 (hosting/cutover) consumes finalized URL contract — 04.1 must close before 06.

### Claude's Discretion

- Top-8 featured stories selection — pick by editorial impact + cross-archive variety. Suggested: tic-tac, gimbal, roswell, rendlesham, trans-en-provence, varginha, falcon-lake, phoenix-lights.
- Dropdown styling: match existing nav typography (mono, 0.08–0.24 em letter-spacing per CLAUDE.md §3.3).
- Story page hero: extract first paragraph from legacy `<article>` as lede; reuse `.hero-sub` styling.

</decisions>
