## Goal

Update `scripts/copy-legacy-archives.sh` so that all `git ls-files` reads and `cp` writes account for the `legacy/` directory prefix introduced in Plan 04.1-01, while preserving the existing dist-URL contract verbatim (`legacy/geipan/index.html` → `dist/geipan/index.html`, NOT `dist/legacy/geipan/index.html`). Drop the four top-level static page copies (`search.html`, `stats.html`, `timeline.html`, `whatsnew.html`) — those will be either Astro-served (timeline/whatsnew via 04.1-04) or removed (search.html is already Astro per `src/pages/search.astro`; stats.html is parked-410 per 04.1-06). Keep the assets/slideshow/slideshow-2 root-level copies untouched (they are NOT legacy per CONTEXT.md decisions). Keep Pagefind invocation untouched. Defensive guard: the prefix-strip MUST only fire for paths that start with literal `legacy/` followed by `/` — never strip the substring `legacy` from a path like `assets/legacy-fonts/...` or a hypothetical future `legacy-archive-snapshot/...` directory (cross-reference: W-2 in 04.1-PLAN-CHECK.md).
